# Описание функций и переменных

## `parse_args() -> str`
- **Назначение**: обрабатывает аргументы командной строки.
- **Локальные переменные**: нет (использует `sys.argv`).
- **Возвращает**: путь к файлу (строка). Если аргумент не передан – `"./data/tmp.v"`.

---

## `read_file(file_path: str) -> str`
- **Назначение**: читает содержимое файла.
- **Аргументы**: `file_path` – путь к файлу.
- **Локальные переменные**: `f` – файловый объект (в контекстном менеджере `with`).
- **Возвращает**: содержимое файла как строку.
- **Ошибка**: при отсутствии файла выводит сообщение и завершает программу.

---

## `extract_signals(code: str) -> list[dict]`
- **Назначение**: извлекает объявления сигналов (`input`, `output`, `inout`, `logic`, `reg`, `wire`) и их размерность.
- **Аргумент**: `code` – строка с Verilog-кодом.
- **Локальные переменные**:
  - `signals` – список накапливаемых результатов.
  - `pattern` – скомпилированное регулярное выражение.
  - `m` – объект совпадения.
  - `msb`, `lsb` – строки с числами диапазона.
  - `range_str` – итоговая размерность (например, `"[7:0]"` или `"[0:0]"`).
  - `names_part` – часть строки после диапазона с именами через запятую.
  - `names` – список имён после разбиения.
  - `name` – отдельное имя сигнала.
- **Возвращает**: список словарей с ключами `"range"` и `"name"`.

---

## `find_assigns(code: str) -> list[dict]`
- **Назначение**: находит все `assign signal = { ... };` с учётом вложенных скобок.
- **Аргумент**: `code` – строка с кодом.
- **Локальные переменные**:
  - `assigns` – список результатов.
  - `start_pattern` – регулярное выражение для поиска начала `assign`.
  - `pos` – позиция для продолжения поиска.
  - `m` – объект совпадения.
  - `signal` – имя сигнала.
  - `brace_depth` – счётчик глубины вложенности фигурных скобок.
  - `end` – позиция закрывающей `;`.
  - `i` – индекс в цикле по символам.
  - `expression` – извлечённое выражение между `{` и `}` (без внешних скобок).
- **Возвращает**: список словарей с ключами `"signal"` и `"expression"`.

---

## `filter_assigns(assigns: list[dict], prefix: str) -> list[dict]`
- **Назначение**: фильтрует `assign` по одному префиксу.
- **Аргументы**:
  - `assigns` – список от `find_assigns`.
  - `prefix` – строка-префикс.
- **Локальные переменные**: отсутствуют (используется генератор списка).
- **Возвращает**: новый список словарей, у которых `signal.startswith(prefix)`.

---

## `build_json_data(code: str, prefixes: list = ["port"]) -> dict`
- **Назначение**: строит полную структуру данных для JSON.
- **Аргументы**:
  - `code` – строка с исходным кодом.
  - `prefixes` – список префиксов для фильтрации (по умолчанию `["port"]`).
- **Локальные переменные**:
  - `signals` – результат `extract_signals`.
  - `all_assigns` – результат `find_assigns`.
  - `filtered_items` – список для сбора итоговых объектов.
  - `seen_signals` – множество для проверки уникальности сигналов.
  - `prefix` – текущий префикс в цикле.
  - `filtered` – отфильтрованный список для одного префикса.
  - `item` – текущий элемент.
  - `signal` – имя сигнала.
  - `expr` – временная строка для очистки.
  - `elements` – массив элементов конкатенации.
- **Возвращает**: словарь с ключами `"signals"`, `"all_assigns"`, `"filtered_assigns"`.

---

## `main() -> None`
- **Назначение**: главная функция, управляющая выполнением.
- **Локальные переменные**:
  - `file_path` – путь к файлу (получен через `parse_args()`).
  - `code` – содержимое файла (получено через `read_file()`).
  - `prefixes` – список префиксов (задаётся в коде, по умолчанию `["port"]`).
  - `data` – полная структура данных (получена через `build_json_data()`).
  - `output` – словарь, содержащий только `all_assigns` и `filtered_assigns` (для печати).
- **Действия**: выводит `output` в JSON с отступами.

---

# Структура полного JSON

```json
{
  "signals": [
    {"range": "[7:0]", "name": "bulba"},
    {"range": "[0:0]", "name": "blabla"}
  ],
  "all_assigns": [
    {"signal": "port_o", "expression": "2'b00, blabla, lol[2:0], bulba[3], byaka"},
    {"signal": "port_x", "expression": "2'b0, blabla, 2'b00, lol[2:0], 3'b0, bulba[7:4], byaka"}
  ],
  "filtered_assigns": [
    {"signal": "port_o", "elements": ["2'b00", "blabla", "lol[2:0]", "bulba[3]", "byaka"]},
    {"signal": "port_x", "elements": ["2'b0", "blabla", "2'b00", "lol[2:0]", "3'b0", "bulba[7:4]", "byaka"]}
  ]
}
```

### Пояснение полей
- **`signals`** – массив объектов с размерностью (`range`) и именем (`name`) каждого сигнала.
- **`all_assigns`** – массив всех найденных `assign` с именем сигнала и выражением (содержимое между `{` и `}`).
- **`filtered_assigns`** – массив отфильтрованных `assign` (по списку префиксов), где выражение разбито на элементы (`elements`).
