# Release Notes - parcer_port_source.py

## [1.0.0] - 2026-09-08 13:00
### Initial Release
- Создан базовый каркас скрипта
- Реализована функция read_file_lines() для чтения файла
- Реализована функция filter_assigns_by_port() для фильтрации по порту-источнику
- Реализована функция parse_assign_line_bitwise() с базовым парсингом

## [1.1.0] - 2026-09-08 13:30
### Added
- Добавлена поддержка конкатенации { ... } в правой части
